#### Documentation.

5 April 2026. How to run the Rest API so far.
The Rest API can be accessed in the terminal/command line by running 'python app.py', where the data can be retrieved by using 'curl http://127.0.0.1:5000/.' If you are running it in PyCharm, you can also run 'Flask app --debug' to allow it to auto update without you having to repeatedly enter it in, I believe.

To set up your api key, create a file called .env in the root directory of your project and type `TMDB_API_KEY = <your_key>`
into the file.
